# 投資×AI note工房

スマホだけで「投資におけるAI活用法」の note 記事を作り、収益化するための一式です。

| ファイル | 内容 |
| --- | --- |
| `index.html` | スマホ用ツール。ロードマップ／AI指示文メーカー／ネタ帳30本／収益化／注意点 |
| `samples/01_自己紹介.md` | 最初の1本（自己紹介記事）の下書き |
| `samples/02_無料記事_決算短信.md` | 集客用の無料記事の下書き |
| `samples/03_有料記事_プロンプト集.md` | 有料記事（500円想定）の下書き |

下書きの【　】の部分は、あなたの体験や確認した数字に置き換えてから公開してください。

## 考え方：「完全自動」ではなく「半自動」

- note には公式の投稿APIがなく、非公式ツールでの自動投稿は規約違反・アカウント停止のリスクがあります。
- AIだけで作った記事は誰でも作れるため、差別化できず売れません。
- そこで **AIが下書きの8割を作り、あなたが体験と確認で2割を足す** 形にします。1日15分で回せます。

## 毎日の流れ（15分）

1. ネタ帳からテーマを選ぶ（2分）
2. 記事メーカーに「やってみたことメモ」を書いて指示文をコピー（3分）
3. Claude / ChatGPT アプリに貼り付けて下書きを作る（3分）
4. 体験を足し、【要確認】の数字を公式サイトで確認（5分）
5. note アプリに貼り付け、見出し画像・ハッシュタグを付けて公開、Xで告知（2分）

## 30日ロードマップ

1. アプリ（note、Claude または ChatGPT）を入れて登録
2. プロフィール作成（名前は「何の人か」が分かるもの）
3. 立ち位置は「AIを投資に使ってみる実験の記録係」。先生にならなくていい
4. 自己紹介記事を公開
5. 無料記事を10本以上（2日に1本）
6. 30日目前後に、反応の良かったテーマの「完全版」を有料記事（300〜500円）に
7. 有料記事が3本たまったらマガジン、ファンがついたら定期購読・メンバーシップへ

## 成功者に共通するノウハウ

- **一次情報が商品**：実際にAIへ入力した質問、返ってきた答え、間違いと気づき方。
- **無料で信頼 → 有料**：最初の10〜20本は無料。
- **継続**：最初の1〜3か月は数字が動かないのが普通。30本が最初の壁。
- **外部導線**：毎回Xで告知する。
- **売れる形は「すぐ使える物」**：プロンプト集、手順書、テンプレート。
- **有料記事の型**：悩み → 得られるもの → 目次 → 一部を見せる → ここから有料 → 全手順・全テンプレ → 免責文。

## 必ず守ること（投資ジャンル）

- 特定銘柄の売買推奨・売買タイミングの助言を有料で行わない（金融商品取引法の投資助言業に当たるおそれ）。売るのは「AIの使い方・調べ方」。
- 「必ず儲かる」「元本保証」などの断定・誇大表現を使わない。
- アフィリエイトは冒頭に「PR」と明記（2023年10月からのステマ規制）。
- AIの数字は公式情報（会社IR、EDINET、TDnet、金融庁、国税庁）で確認する。
- 他人の有料記事・レポートを要約して載せない。
- 副業所得が年20万円を超えたら確定申告（会社員の場合）。

手数料やアプリの画面、制度の細かい条件は変わることがあるため、公開前に note 公式ヘルプや各公式サイトで最新情報を確認してください。
