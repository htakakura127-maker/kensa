# 電流モニター（Apps Script）

Informetis の CH1 / CH2 電力を、遅れを減らして表示する Apps Script 用ファイルです。

## 入れ替え方

1. Apps Script のプロジェクトを開く
2. `コード.gs` の中身を全部消して、`Code.gs` の中身を貼り付ける
3. `Monitor.html` の中身を全部消して、このフォルダの `Monitor.html` の中身を貼り付ける
4. 保存して「デプロイ」→「デプロイを管理」→ 鉛筆マーク →「バージョン：新しいバージョン」→「デプロイ」
   （URLは今と同じまま使えます）

## 前の版から変えたところ

- **毎回ログインしない**：ログイン後のCookieを6時間保存して使い回すので、通常は通信が3回→1回になる。期限切れのときだけ自動でログインし直す
- **取りに行くタイミング**：5秒ごとの固定ではなく、機器の更新間隔（直近2点の時刻差）から「次の点が出るはずの時刻」に合わせて取りに行く
- **「データの遅れ」を表示**：取得してからの秒数ではなく、機器のデータ時刻から今まで何秒たっているかを表示
- **20A / 25A 超えで背景色**：20A超で橙、25A超で赤
- **裏にしたら止まる**：画面を閉じている間は取得しない（Apps Script の1日の通信回数の上限対策）
- 複数の端末で同時に開いても、1.5秒以内の取得結果は共有して通信を増やさない

## 限界

機器が Informetis にデータを送る間隔より速くはなりません。画面下の「機器の更新間隔」がその間隔です。
