# 電流モニター（Apps Script）

Informetis の CH1 / CH2 電力を、遅れを減らして表示する Apps Script 用ファイルです。

## 入れ替え方

1. Apps Script のプロジェクトを開く
2. `コード.gs` の中身を全部消して、`Code.gs` の中身を貼り付ける
3. `Monitor.html` の中身を全部消して、このフォルダの `Monitor.html` の中身を貼り付ける
4. 保存して「デプロイ」→「デプロイを管理」→ 鉛筆マーク →「バージョン：新しいバージョン」→「デプロイ」
   （URLは今と同じまま使えます）

## 前の版から変えたところ

- **毎回ログインしない**：ログイン後のCookieを6時間保存して使い回すので、通常は通信が3回→1回になる。期限切れのときだけ自動でログインし直す
- **取りに行く間隔**：元のページは1秒ごとに最新値が変わるので、5秒ごとの固定をやめ、前回の取得開始から1秒たったら次を取りに行く
- **「データの遅れ」を表示**：機器のデータ時刻から今まで何秒たっているかを表示。「値の更新: ○秒前」が5秒を超えると橙、15秒で赤
- データ時刻「10/28 18:37:28」（年なし）を日本時間の今年として読む
- **20A / 25A 超えで背景色**：20A超で橙、25A超で赤
- **裏にしたら止まる**：画面を閉じている間は取得しない（Apps Script の1日の通信回数の上限対策）
- 複数の端末で同時に開いても、0.9秒以内の取得結果は共有して通信を増やさない

## 限界

- Informetis のデータ時刻は、実際の時刻より約6分20秒遅れています（2026-10-28 の診断）。元のサイトの遅れか機器の時計ずれかは未確認
- Apps Script の外部通信は1日の回数に上限があります（無料アカウントで約2万回）。1秒ごとだと開きっぱなしで約5時間半ぶんです

## 診断ブックマークレット

`diagnose-bookmarklet.txt` を Safari のブックマークのURLに貼り、Informetis のグラフ画面で実行すると、自動更新を止めて60秒間、元のデータの更新タイミングと遅れを測ります。
